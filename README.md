# أداة مراجعة الأكواد واكتشاف الأخطاء بالذكاء الاصطناعي
**AI-Powered Code Review & Bug Detection Tool** · التصنيف: هندسة برمجيات

> هذا المشروع خاص بشركة/عميل محدد، والكود المصدري غير منشور.
> Private client work — the source code is not public.

## نبذة عن المشروع
نموذج ML يكتشف مشاكل الكود والأخطاء في طلبات GitHub.

## أبرز النقاط
- نموذج ML مدرب على مستودعات مفتوحة المصدر
- FastAPI + تكامل GitHub Webhook
- لوحة React لمقاييس جودة الكود

## الدور
مهندس برمجيات: تصميم المعمارية وبناء المكونات الأساسية والنشر والأتمتة.

## التقنيات المستخدمة
Python, FastAPI, scikit-learn, PostgreSQL, React, TypeScript, Docker, GitHub API
